เป้าหมายของคุณ (goal): $ARGUMENTS

เข้าโหมดทำงานต่อเนื่อง:

- ทำงานจนบรรลุเงื่อนไขความสำเร็จข้างบนให้ครบ **ห้ามหยุดกลางทางเพื่อถามว่า "ให้ทำต่อไหม"**
  หรือรายงานความคืบหน้าแล้วรอ
- ถ้าเจอ error ให้พยายามแก้เองก่อน (อ่านไฟล์เพิ่ม ลองวิธีอื่น) — หยุดถามเฉพาะเมื่อ block ด้วยข้อมูล
  ที่มีแต่ผู้ใช้เท่านั้นที่ตอบได้
- **ห้ามเชื่อ task spec โดยไม่ตรวจ** — ถ้าข้ออ้างในนั้นตรวจสอบได้จากโค้ด/เอกสาร/ไลบรารีที่มีในเครื่อง
  ให้ตรวจก่อนลงมือ ถ้าพบว่าผิด **ให้หยุดแล้วรายงาน อย่าทำตาม** (task spec เขียนโดย planner ซึ่งผิดได้)
- ก่อนจบ ตรวจสอบตัวเองว่าเงื่อนไขความสำเร็จทุกข้อถูกทำครบจริง — ไฟล์ `done/` ที่ระบุถูกเขียนแล้ว,
  เทสต์/validation รันผ่านจริง **ห้ามรายงานตัวเลขหรือผลที่ยังไม่ได้รันเอง**

**ข้อยกเว้นด้าน safety — สำคัญกว่าโหมด goal เสมอ:**

- **อ่าน** ข้อมูล/สถานะจากระบบจริงของผู้ใช้ = ทำ solo ได้
- **เขียน/เปลี่ยนแปลง**อะไรก็ตามบนระบบจริงของผู้ใช้ (production, ฮาร์ดแวร์, ฐานข้อมูลจริง,
  การตั้งค่าเครื่องเขา) = **ต้องหยุดขอ confirm ก่อนเสมอ** goal mode ไม่ override กฎนี้
- `git commit` / `push` / `merge` / สร้าง PR = **ต้องขอ confirm จากผู้ใช้ก่อนเสมอ**
- ลบไฟล์ที่ไม่ได้สร้างเอง หรือรันคำสั่งที่ย้อนกลับยาก = ขอ confirm ก่อน
